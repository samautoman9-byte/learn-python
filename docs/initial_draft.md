# 商家版外卖点餐软件（初稿）

本初稿聚焦 **商家工作台** 的关键闭环：菜单管理、订单处理、出餐节奏、经营分析。目标是给出可落地的最小可用版本（MVP）轮廓，后续可按优先级扩展。

## 产品目标
- 高效处理外卖订单：兼顾高峰期的接单、制作、备餐、出餐节点。
- 降低错单率：标准化菜品信息、出餐口提示与状态同步。
- 经营可视化：实时销量与热门菜品，帮助商家优化备货与加价策略。

## 用户场景（商家）
1. **开店准备**：配置营业时间、配送范围、起送价、预计出餐时间。
2. **菜单管理**：上下架菜品、设置库存/售罄状态、配置套餐与加价项。
3. **接单出餐**：多渠道订单汇聚（美团/饿了么/自建小程序），可一键接单、拒单，按状态展示。
4. **备餐排程**：厨房视图按出餐时间排序，支持催单、延时、出餐提示音。
5. **售后与评价**：订单售后记录、退款处理、差评预警与解决建议。
6. **运营分析**：销量、毛利、复购率、热门时段分布，支持导出。

## MVP 能力分层
- **接单层**：订单接入（第三方平台 API + 自营小程序）、去重与幂等处理、状态同步。
- **菜单层**：菜品/套餐管理、库存/售罄、加料与规格（辣度/大小/温度）。
- **制作层**：出餐状态流转（新订单→已接单→制作中→待取餐→已完成/取消）、催单/延时。
- **通知层**：前场工位提示（声音+大屏）、骑手到店/取餐提醒。
- **数据层**：实时销量面板、品类热力图、出餐时长监控。

## 数据模型（草案）
- `MenuItem`：`id`、`name`、`price`、`category`、`available`、`description`
- `OrderItem`：`menu_item_id`、`quantity`、`note`
- `Order`：`id`、`items`、`status`、`customer_name`、`channel`、`special_instructions`
- `OrderStatus`：`new` → `accepted` → `preparing` → `ready` → `completed` / `cancelled`

## 交互与流程
- **接单视图**：按渠道+状态分栏，新订单提示音，自动接单/手动接单可配置。
- **制作看板**：显示预计出餐时间、剩余时间倒计时，支持批量状态更新。
- **售罄处理**：一键售罄，自动同步到渠道；支持定时恢复。
- **打印/出餐小票**：新订单自动打印，含取餐号/渠道。
- **运营面板**：当日营收、出餐中订单数、超时预警、催单量。

## 技术方案建议（初稿）
- **前端**：React/Vue + WebSocket（实时订单），可配大屏/平板端自适应。
- **后端**：Python（FastAPI）或 Node（NestJS），提供 REST + WebSocket。任务队列（Celery/RQ）处理高峰期异步任务（打印、消息推送）。
- **数据存储**：PostgreSQL（交易、菜单），Redis（队列、实时看板）、对象存储（小票模板）。
- **第三方对接**：美团/饿了么开放平台 API 封装为统一 `ChannelAdapter`，处理签名、重试与回调校验。
- **监控**：结构化日志 + 链路追踪，关键指标（接单成功率、出餐时长）上报。

## 里程碑拆解
1. **MVP（2-3 周）**
   - 订单接入与状态流转（含打印/声音提示）
   - 菜单管理与售罄同步
   - 简易数据看板（实时销量、出餐中订单）
2. **扩展（4-6 周）**
   - 多门店/多角色权限、出餐口分单
   - 预售/预约单、库存联动
   - 售后与评价闭环、营销活动（满减/会员）
3. **优化**
   - 智能备菜建议、出餐时长预测
   - 高可用与容灾方案

```bash
python -m merchant_app.cli
```

输出示例会展示：菜单查看、下单、状态推进、售罄处理与订单汇总。
